# Метраж досок — Android APK

Ввод: длина в **миллиметрах**, количество в **штуках**. Результат — **погонные метры**.

Функции: запомнить расчёт, стереть поля, удалить ошибочную строку, итог за смену, завершить смену, локальный архив, просмотр и отправка отчёта.

Данные хранятся локально в SharedPreferences. Приложение не требует интернета и не отправляет данные на сервер. При удалении приложения данные обычно удаляются; регулярно отправляйте отчёты себе для резервной копии.

## Как собрать APK с телефона

1. Создайте бесплатный аккаунт на github.com и новый **пустой публичный или приватный репозиторий** `board-meter`.
2. Распакуйте ZIP на телефоне. На странице репозитория выберите **Add file → Upload files**, загрузите **содержимое** папки проекта с сохранением путей, включая `.github/workflows/build-apk.yml`. На мобильном сайте GitHub загрузка папок может быть неудобной: включите «Версия для ПК» или используйте приложение/веб-редактор github.dev. Альтернативно загрузите ZIP как исходник через другой Git-клиент с поддержкой папок.
3. После коммита откройте вкладку **Actions → Сборка APK → Run workflow** (или дождитесь автоматического запуска после push в main/master).
4. Дождитесь зелёной галочки. Откройте выполненный запуск, раздел **Artifacts**, скачайте `BoardMeter-APK`.
5. Распакуйте скачанный архив и установите `app-debug.apk`. Android может запросить разрешение на установку из браузера или файлового менеджера.

GitHub Actions собирает отладочный APK с тестовой подписью. Для личного использования это нормально. Не публикуйте этот APK в Google Play. Для обновлений рекомендуется хранить тот же ключ подписи, иначе может понадобиться удалить предыдущую установку (и потерять локальные данные).

Требования сборки: JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, SDK 35.
